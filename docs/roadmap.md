# LivingRuntime 改版与功能规划

按顺序做，前一项上线后再开始下一项。英文读者优先：每一项都要先在英文模式下好用，中文模式不能退步。

规则不变：页面只经 `apps/api` 读数据，公开出口都走 `packages/backend/src/publication/`，读者打开页面不触发模型调用；图谱只展示 Graphiti 已有的关系，事实是提取后的陈述，不标成原文引述。

## 1. 第三版视觉（进行中）

“事件 → 关系 → 证据”的版式，和上游框架的暖纸色加青色区分开。

- 全站色板换成靛蓝主色加热度色谱（冷蓝、橙、红），分类各有一色；夜色面板用在首页主视觉、图谱和日报卡片上；深色模式同步。
- 字体：数字和站名用 Instrument Serif，数据和标签用 IBM Plex Mono，正文仍用系统中文字体。字体文件自托管，不依赖 Google Fonts。
- 首页：顶部一行“24 小时脉搏”（采集、精选、入图报道、实体、关系）；主视觉是当前热度第一的事件，左边是热度、来源数、一手来源和走势，右边是这个事件在图谱里的关系和一条证据；下面是热度 2–5 名和信息流。
- 英文模式的信息流卡片以来源为先：原文标题、来源名、一手标记、“Read source” 按钮，不显示中文摘要。
- 事件页、热点页、日报和图标统一换色；图谱画布的颜色改用 CSS 变量。
- 行情条：读已有的 `/api/market/spot`，只显示当前价格快照，注明数据来自 Binance/OKX。

## 2. 实体档案页

把 `/knowledge/entity/:key` 做成真正的档案：按 `validAt` / `invalidAt` 排出关系的变化时间线，列出相关事件和报道，允许搜索引擎收录。

## 3. 关注实体和主题

不用注册，关注列表存在读者本机；首页可切到“我关注的”。每个主题和实体提供自己的 RSS。

## 4. 日报里的“图谱今日变化”

按规则统计当天新增、失效的关系和新出现的实体，写进日报，不调用模型。

## 5. 事件与价格

worker 定时存行情快照，事件页显示事件前后相关资产的价格变化。只做并列展示，不做因果判断。

## 6. MCP 图谱工具

MCP 增加查询实体、查询事件关系两个工具，读的是已经公开的图谱接口。

## 之后

- 可收录的英文版：稳定的 `/en` 地址、`hreflang`、完整的英文标题和摘要。
- 卡片上显示信源等级（需要先把等级加进公开字段）。
